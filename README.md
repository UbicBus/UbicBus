# RutaBus — sitio web promocional

Landing page responsive en HTML, CSS y JavaScript puro.

## Archivos
- `index.html`: estructura y contenido de la página.
- `styles.css`: diseño visual, animaciones y adaptación a móviles.
- `script.js`: menú móvil, año automático y preguntas frecuentes.
- `assets/busi.png`: imagen PNG transparente de Busi, usada como mascota y favicon.
- `assets/busi.svg`: versión vectorial original de respaldo.

## Cómo abrir
1. Descarga y descomprime `rutabus_web.zip`.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en tu navegador. También puedes usar la extensión Live Server.

## Personalización antes de publicar
- Cambia el correo `hola@rutabus.app` por el correo oficial.
- Cuando la app esté publicada, reemplaza el botón de contacto por los enlaces reales de Google Play y App Store.
- Revisa que las funciones descritas coincidan con la versión final de la aplicación.
- Si tienes capturas reales de la app, puedes reemplazar el mockup dibujado en HTML por esas imágenes.

## Nota sobre el diseño de referencia
El enlace de Figma no permitió cargar su contenido desde este entorno. Por eso, esta versión se construyó usando la información disponible sobre RutaBus: planificación de rutas, seguimiento GPS, favoritos, paraderos cercanos, alertas, comparación de recorridos, reportes ciudadanos y modo sin conexión. La identidad visual usa azul, blanco y amarillo, con Busi como protagonista.
